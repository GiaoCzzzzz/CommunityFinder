## User Flow Animation

### Step 1: User on MainPage
```
  MainPage
  ┌─────────────┐
  │ [🤖] [⚙️]  │  ← User clicks 🤖 button
  └─────────────┘
```

### Step 2: AI Chat Opens
```
  MainPage              AIChatPage
  ┌─────────────┐      ┌─────────────────┐
  │ [🤖] [⚙️]  │  →   │ 👋 Welcome!    │
  └─────────────┘      │ Type your query│
                       └─────────────────┘
```

### Step 3: User Types Query
```
  AIChatPage
  ┌───────────────────────────┐
  │ User: "周末运动课程"      │
  │                            │
  │ [Type here...] [Send]      │ ← User types & sends
  └───────────────────────────┘
```

### Step 4: AI Responds
```
  AIChatPage
  ┌───────────────────────────┐
  │ User: "周末运动课程"      │
  │                            │
  │ AI: ✨ Understood!        │
  │ 📅 Day: Saturday          │
  │ 📚 Category: Sports       │
  │                            │
  │ [✓ Apply Filters]          │ ← Button appears
  └───────────────────────────┘
```

### Step 5: Filters Applied
```
  AIChatPage              MainPage (Updated)
  ┌─────────────┐        ┌──────────────────┐
  │ [Apply]     │   →    │ Day: [Saturday▼]│
  └─────────────┘        │ Search results... │
                         └──────────────────┘
```
